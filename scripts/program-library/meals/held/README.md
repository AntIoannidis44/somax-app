# Held - do not ship

`ais-sports-nutrition-meals.json` (103 recipes from the Australian Institute of
Sport, ausport.gov.au) is licensed **CC BY-NC-ND 4.0**: non-commercial only and
no derivative versions. Our entries rewrite methods and swap branded items,
which is arguably a derivative, and Somax may be commercial - so these fail the
"100% confident we can use it" rule and are NOT loaded into the app.

They can ship only with written permission from the Australian Sports
Commission (copyright request form: https://www.ausport.gov.au/legal_information/copyright).
Somax's own sports-nutrition meals are built from the general principles
learned (recovery/timing/portion rules), not from these recipes.

Generator/parser: ../../tools/parse_ais_recipes.py, gen_sports_nutrition_meals.py,
validate_sports_nutrition_meals.py.
